# Krav0n.github.io

אתר הקישורים של Krav0n (GitHub Pages).

## מבנה הפרויקט

```
├── index.html            ← העמוד הראשי (HOME / INFO / LEADERBOARD)
├── accessibility.html    ← הצהרת נגישות
├── privacy.html          ← מדיניות פרטיות
├── js/
│   └── leaderboard.js    ← משיכה ורענון אוטומטי של הטבלאות
├── data/
│   └── leaderboard.json  ← נתוני הטבלאות (כרגע נתוני דמה)
└── assets/
    ├── images/           ← profile.png, favicon.png
    └── badges/           ← badge_*.png (תגי המנויים)
```
